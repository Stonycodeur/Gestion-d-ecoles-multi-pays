# Contribuer
- Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
- Une branche par phase (`phase-N-nom`), fusionnée dans `main` quand la phase est verte.
- TypeScript strict, `flutter analyze` sans erreur, ESLint/Prettier.
- Aucune règle nationale dans le code : tout passe par le référentiel pays (`infra/sql`).
- Jamais de secret, keystore, certificat ou `google-services.json` réel dans le dépôt.

Le dépôt est propriétaire (`LICENSE`) : aucune contribution, copie ni réutilisation sans accord écrit préalable de STONY-TECHNOLOGIE. Toute contribution acceptée devient sa propriété.
